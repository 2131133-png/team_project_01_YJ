# 중고거래 피해 대응 길잡이

온라인피해 365센터 상담을 돕는 **중고거래 피해 첫 진단·기관 안내** 웹 서비스입니다. (공공행정 프로젝트 1조 시제품)

피해자가 버튼을 누르거나 상황을 글로 쓰면, 길잡이가 사기·분쟁 중 어디에 가까운지 가려 **먼저 가야 할 기관**과 **할 일**을 알려 주고, 기관에 낼 **증거 정리표**를 만들어 줍니다.

> 길잡이는 사기 여부를 판정하지 않고, 기관에 대신 접수하지도 않습니다. "어디에 먼저 가야 하는지"를 안내합니다. 결과는 법적 판단이 아닙니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 안전 확인 | 자해·자살을 암시하는 표현이 있으면 어떤 결과보다 먼저 **☎ 109** 안내를 맨 위에 띄웁니다 |
| 상황 진단 | 글로 쓰면 AI가 사실 항목(송금 방법·수령 상태·연락 상태 등)으로 정리하고, 모르는 칸은 버튼으로 되묻습니다. 글쓰기가 어려우면 버튼만으로도 끝까지 진행할 수 있습니다 |
| 규칙표 분류 | 분류는 AI가 아니라 **미리 정한 규칙표(코드)**가 합니다. 같은 사실이면 누가 써도 같은 결과가 나옵니다 |
| 기관·할 일 안내 | 결과마다 응급조치, 안내 기관, 근거 문서 이름을 보여 줍니다 |
| 증거 정리표 | 항상 같은 6칸 양식의 `.txt` 를 내려받습니다. 서버에 저장하지 않습니다 |
| 상담원 연결 | 판단이 어려우면 365센터(☎ 142-235)로 연결하고, 정리한 내용을 복사해 전달합니다 |

**결과 4가지**

| 결과 | 색 | 먼저 갈 곳 |
|---|---|---|
| 사기 의심 | 빨강 | 이체한 은행(지급정지 문의) → 경찰청 사이버범죄 신고시스템 |
| 거래 분쟁 | 파랑 | 판매자에게 요청 → 거래 플랫폼 → 전자문서·전자거래분쟁조정위원회 |
| 범위 밖 | 초록 | 착오송금: 은행·예금보험공사 / 보이스피싱: 112 |
| 판단 어려움 | 회색 | 온라인피해 365센터 상담원 |

## 폴더 구성

```
public/     이용자가 보는 화면 (index.html · app.js · style.css)
api/        서버 함수
  extract.js      문장 → 사실 항목 (계좌·전화번호를 가린 뒤 AI 호출)
  classify.js     사실 항목 → 결과 (규칙표, AI 없음)
  health.js       어느 AI 키가 들어 있는지 (값은 보여 주지 않음)
  _lib/ai.js      AI 순서 호출 · 모델 목록 조회 · 시간 초과 8초
  _lib/rules.js   사실 항목 값 목록 · 위기 단어 · 분류 규칙표
  _lib/guides.js  결과별 안내 문구와 근거 문서 이름
docs/답변참고문서/  안내 문구의 근거가 되는 공공기관 자료
server.js   로컬 실행용 (화면 + /api 를 함께 띄움)
vercel.json 배포 설정
```

## 로컬에서 실행하기

Node.js 22 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 주소 끝에 `?debug` 를 붙이면 어느 AI가 답했는지 볼 수 있습니다.

## API 키

키는 코드에 넣지 않고 `.env` (로컬)와 Vercel Environment Variables (배포)에만 같은 이름으로 넣습니다. `.env` 는 저장소에 올리지 않습니다.

| 이름 | 용도 |
|---|---|
| `CLAUDE_API_KEY` | 첫 번째로 부르는 AI |
| `GROQ_API_KEY` | Claude가 실패하면 |
| `GEMINI_API_KEY` | Groq까지 실패하면 |

이름마다 키는 하나만 넣습니다. 키가 하나도 없어도 서비스는 「시연 값」과 버튼 질문으로 동작합니다.

## 지키는 원칙

- 돈·비밀번호·인증번호를 묻지 않습니다 (365센터 사칭 사기 주의).
- 피해 내용과 정리표를 서버에 저장하지 않습니다. 브라우저에 남는 것은 「큰 글씨」 설정뿐입니다.
- 시험에는 지어낸 문장만 쓰고, 실제 개인정보가 든 문서는 넣지 않습니다.
