# 답변참고문서 점검 메모

이 파일은 서버가 읽지 않습니다(서버는 `청킹/`만 읽음). 서버를 만들 때와 자료를 보강할 때 참고합니다.

## 서버(api)를 만들 때 지킬 규칙

1. **기관 이름 풀어쓰기**: 출처가 "방송통신위원회"인 문서를 근거로 답할 때는 "방송통신위원회(현 방송미디어통신위원회)"로 적는다. 출처 줄 자체는 발간 당시 이름 그대로 둔다.
2. **근거가 없으면 모름**: `청킹/`에 근거가 없는 질문은 "문서에 없어 답하기 어렵다"고 말하고 온라인피해 365센터(☎142-235)를 안내한다.
3. **착오송금 반환지원 금액**: 상한 금액이 자료마다 달라(1억 원 / 5천만 원) 금액 조각을 뺐다. 금액을 물으면 예금보험공사(☎1588-0037)에 확인하도록 안내한다.
4. **365센터 운영시간**: 답변과 화면에는 문서 기준 "월~금 09:00~12:00, 13:00~18:00"을 쓴다.
5. **판정 금지**: 사기 여부나 처벌 수위(형량)를 단정하지 않는다. 형량 문장은 조각에서 뺐다.
