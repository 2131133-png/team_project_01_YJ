이용자 화면이 서버 함수 두 개를 부르고, 서버가 AI와 규칙표를 잇는다. AI는 사실만 정리하고, 판단은 규칙표(코드)가 한다.

저장하지 않는 구조서버에는 데이터베이스가 없다. 피해 내용·정리표는 이용자 기기의 화면 안에만 있고, AI에 보낼 때는 계좌·전화번호를 가린다. 브라우저에 남는 것은 「큰 글씨」 설정 하나뿐이다.
근거와 범위안내 문구마다 docs/답변참고문서 의 문서 이름을 붙인다. 공공 API는 쓰지 않는다(기획서에 없음). 위기 표현은 화면과 서버 두 곳에서 확인한다.
